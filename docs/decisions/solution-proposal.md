# 方案提议

## 任务ID
TASK-20260424-007

## 任务名称
Runtime Prototypes: QwenPaw 直连聊天页最小闭环 — Chat-First 主界面重构

## 本轮任务理解
当前原型页虽然已经具备最小聊天闭环，但页面结构仍以“顶部状态卡片 + 配置主导”组织，首屏主焦点偏离聊天任务。
本轮目标是在不改动聊天流、认证、Agent、运行时配置底层逻辑的前提下，重做页面信息层级，让页面回到“聊天主界面”定位：

- 第一眼先看到当前会话、消息流和输入区
- 会话控制保留，但降到右侧次级区域
- 运行时配置默认折叠，成为真正的三级操作

## 推荐方案
采用“组件拆分 + 布局重排 + 视觉收敛”的方案，在现有 Vue3 原型结构上增量重构，不另起框架、不引入新状态管理。

## 精确执行步骤

### 步骤1：拆出聊天主界面组件
1. 新增 `ChatHeader.vue`
   - 承载当前会话标题、副标题、轻量状态 badge、错误提示
2. 新增 `StatusSummary.vue`
   - 用紧凑 summary 替代原顶部大卡片
3. 重构 `MessageList.vue`
   - 去掉原有标题区，只保留消息流与空状态
4. 重构 `ChatInput.vue`
   - 改为底部 composer，输入框默认 3 行、自适应高度，发送按钮成为唯一强强调按钮

### 步骤2：拆出右侧次级侧栏
1. 新增 `SessionControls.vue`
   - 承载 Agent 切换、停止生成、清空会话
2. 新增 `RuntimeSidebar.vue`
   - 统一编排登录卡片、会话控制、运行时配置折叠区
3. 运行时配置默认收起
   - 保存/重置按钮只在展开后出现
   - 配置摘要压缩为 chip 级信息

### 步骤3：重构 `ChatView.vue` 编排层
1. 去掉顶部 `config-shell` 和全宽错误横幅
2. 改为“左侧聊天主壳 + 右侧弱化侧栏”两栏布局
3. 补充视图派生状态
   - 会话标题 / 副标题
   - header summary items
   - 输入 placeholder / helper text
   - 运行时配置折叠状态

### 步骤4：重写 `chat.css`
1. 用少量 CSS 变量统一 surface / border / shadow / accent
2. 背景简化为暖中性渐变，移除杂乱纹理感
3. 强化聊天壳体的纵向层级
   - header
   - message stream
   - composer
4. 弱化侧栏卡片和配置区视觉体积
5. 补齐 `1366x768`、`1920x1080` 和窄屏断点表现

## 验收标准
- 首屏焦点落在聊天主区，而不是配置区
- 消息流区域明显大于右侧配置区
- 输入区与发送按钮的操作路径短、主次清晰
- 会话控制可达但不喧宾夺主
- 运行时配置默认折叠，保存配置的视觉权重低于发送消息
- `npm run typecheck` 通过
- `npm run build` 通过

## 已选默认决策
- 不引入新的全局 store 或设计系统
- 不修改 `@proto-shared` 类型、SSE、认证、聊天流业务语义
- 会话标题默认使用当前 Agent 名称
- 运行时配置保留在页面内，但默认收起，不做复杂抽屉
