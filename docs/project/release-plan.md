# 资金AI聊天助手 v0 - 发布计划（Release Plan）

## 1. 文档目的

本文档定义 v0 的发布口径、发布范围、Go-NoGo 条件，用于回答以下问题：

- 当前准备发布的版本是什么
- 发布必须具备哪些能力
- 哪些能力明确不纳入本次发布
- 当前是否已达到可发布状态
- 发布前需要满足哪些条件

本文档不定义阶段交付物，也不定义里程碑。里程碑定义以 `docs/project/milestones.md` 为准。

---

## 2. 发布口径

当前默认发布版本：**v0-internal-demo**

这是一个内部演示版本，不是生产发布版本。其目的是验证骨架、契约和最小闭环是否可在真实环境下跑通，而不是对外提供可用服务。

---

## 3. 版本范围

### 3.1 最小发布范围（Must Have）

以下能力必须在 v0-internal-demo 中具备：

1. **前端聊天界面**
   - 可发起聊天请求
   - 可接收并展示流式响应
   - 会话列表基础展示

2. **Assistant Gateway**
   - 统一消息协议接收与转发
   - Session 映射与管理

3. **Runtime Adapter**
   - QwenPawAdapter 真实可调用
   - MockRuntimeAdapter 保留用于降级

4. **Tool Gateway**
   - 统一工具调用入口
   - 至少 2 个示例工具可被调用
   - 基础参数校验与审计留痕

5. **Decision Service**
   - 独立层存在
   - 可执行简单规则判断

6. **人工确认边界**
   - Confirmation 创建、查看、批准/拒绝可工作
   - 写操作前需确认的链路可演示

7. **基础日志与 trace**
   - 主链路请求可追踪

### 3.2 明确不纳入本次发布（Out of Scope）

以下内容明确不纳入 v0-internal-demo：

1. 复杂业务决策系统 / 深度策略编排
2. HermesAdapter 真实实现（仅预留接口）
3. 工作流引擎真实接入（LangGraph / Temporal / 自研均不接入）
4. 生产写操作接口
5. 前端精细化交互与产品化打磨
6. 限流 / 熔断 / 高可用 / 灾备
7. 大规模多智能体体系
8. 完整 Tool 注册协议与能力目录
9. 主流程编排试点（资金缺口 / 询价交互闭环）
10. 监控 / 回放 / 回退链路

---

## 4. 里程碑完成与发布的关系

**硬规则：里程碑完成不等于版本可发布。**

版本是否可发布，以本文件中的 Go / No-Go 条件为准。

具体说明：

- M1-M3 退出仅代表工程里程碑达成，不代表已形成可发布版本
- M4 退出是发布的前提条件之一，但 M4 退出后仍需通过本文件的 Go-NoGo 判断
- 即使所有里程碑全部完成，若 Go-NoGo 条件不满足，仍不得发布

---

## 5. Go-NoGo 条件

### 5.1 Go 条件（全部满足方可发布）

- [ ] M4 里程碑已全部退出（见 `docs/project/milestones.md` M4 退出条件）
- [ ] 至少 2 个示例工具可端到端调用（前端发起 → Gateway → Runtime → Tool Gateway → 工具执行 → 响应回流）
- [ ] 人工确认链路在真实场景下可工作（创建 → 展示 → 批准/拒绝 → 继续/终止）
- [ ] 所有主链路有结构化日志，请求可追踪
- [ ] 未引入任何生产写操作
- [ ] 未绕过 API 网关直连生产系统
- [ ] L3 敏感数据合规边界已确认（不将 L3 敏感数据发送给云端模型）
- [ ] 可在目标机（非开发机）独立部署并运行演示
- [ ] 无已知阻塞性 bug
- [ ] 发布范围未超出本文件第 3 节定义

### 5.2 No-Go 条件（任一触发即不得发布）

- [ ] 存在未退出的里程碑（M1-M4 任一未完成）
- [ ] 示例工具数量不足 2 个
- [ ] 人工确认边界不可工作
- [ ] 主链路不可追踪（缺少日志/trace）
- [ ] 包含生产写操作接口
- [ ] L3 敏感数据合规边界未确认
- [ ] 无法在目标机独立部署
- [ ] 存在已知阻塞性 bug 未修复
- [ ] 发布范围超出本文件第 3 节定义
